A fix release for the Guition (480 panel): opening the editor could run it out of memory and restart it, again and again.

## Fixed

- **Opening the editor restarted the Guition.** With many screens on Home, opening `http://<your panel>/` could take the panel's memory to nothing, and it restarted each time the open editor asked for its values.
  - The editor now gets the values the panel already has, instead of the panel reading every screen's data again for it.
  - When memory is short the panel says it is busy, and the editor keeps its last values until it can answer.
  - #185
- **The Guition could restart when a card's values changed.** A big card (Media, Overhead) asked for a lot of memory each time its values changed. That fade now takes a fifth of the memory. #185
- **The Guition's screen flickered.** The panel's low-memory check briefly stopped the screen from drawing. It no longer does.
- **More free memory on the Guition.** About 900 KB more is free most of the time.
  - The full-screen album art on the idle screen only holds its memory while the art is on screen, not all the time.
  - Screens the panel keeps ready in the background are let go, biggest first, when memory runs low. They are built again when you open them, and kept again when memory allows.
  - Reading your entities from Home Assistant (search, entity lists) waits until there is enough memory, instead of starting and running out.
  - #185
