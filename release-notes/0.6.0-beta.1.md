The first beta of Facet 0.6. Every screen now lists where its data can come from, Weather works without Home Assistant, the Bins screen is back, and the editor can back up your whole panel. Please try them and tell us how it goes.

## ✨ New

- **[Weather without Home Assistant](https://mrdarrengriffin.github.io/facet/screens/weather/)**: forecasts from Open-Meteo, with no account, read by the panel itself. By default it uses your Home Assistant weather when you have one. <sub>#217</sub>
- **[Back up your panel](https://mrdarrengriffin.github.io/facet/editor/#backup)**: Settings > Backup in the editor exports your screens, cards and settings to a file and imports them again, on this panel or another. Scripts can read the same file from `GET /fw/config`. <sub>#170</sub>
- **[Bins](https://mrdarrengriffin.github.io/facet/screens/bins/)**: the bin collection screen is back on the firmware. <sub>#99</sub>
- **[Idle now](https://mrdarrengriffin.github.io/facet/install/#entities)**: a Home Assistant button that sends the panel to its idle screen straight away. <sub>#207</sub>
- **[Calendar Highlight](https://mrdarrengriffin.github.io/facet/screens/calendar/)**: show the next event's day, or keep today's date with "Nothing else today". <sub>#181</sub>

## 🛠️ Improved

- **[Where each screen's data comes from](https://mrdarrengriffin.github.io/facet/editor/#built-in)**: a free public source first where there is one, then each Home Assistant integration by name. Ones you haven't set up are greyed, and Sample is no longer offered on a panel. <sub>#129 #156 #227</sub>
- **[Media speakers](https://mrdarrengriffin.github.io/facet/screens/media/)**: Auto follows the speaker that's actually playing; unavailable speakers sit at the bottom, greyed. A 1 × 1 card shows the track, not Off. <sub>#224 #182</sub>
- **Long entity ids**: up to 255 characters, like Home Assistant, so long Octopus Energy sensors work. <sub>#218</sub> <!-- no docs: a limit lifted, nothing to explain -->
- **[Guition](https://mrdarrengriffin.github.io/facet/panels/)**: more memory headroom, and reading `/fw/info` no longer makes the screen flicker. <sub>#185 #211</sub>

## 🐛 Fixed

- **Sliding off a button** no longer presses it. <sub>#80</sub>
- **Light mode**: screen fades no longer flash a green tint. <sub>#39</sub>
- **Energy**: TODAY SO FAR is no longer cut off on the Waveshare. <sub>#221</sub>
- **Media**: a stopped player clears its track and art; missing art no longer draws a white square. <sub>#213</sub>
- **Buttons and scenes** never pressed no longer show Unavailable. <sub>#139</sub>
- **Overhead**: the helicopter's rotor blades stay whole at every heading. <sub>#220</sub>
- **Editor**: no add squares cut off below a Home's last row, and a screen's Source shows once. <sub>#223 #226</sub>
- **Problem report** shows the installed version, not 0.4.0-dev. <sub>#184</sub>

## ⬆️ After updating

- **Weather**: with no Source saved, it now picks Home Assistant's weather if you have it, otherwise Open-Meteo. Pick a source in the editor to choose.
