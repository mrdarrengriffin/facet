Facet 0.5.1 fixes one bug in 0.5.0: the editor no longer crashes when it opens on a panel whose saved screens include one this firmware doesn't have. Nothing else changes.

## Fixed

- **[The editor opens on every panel](https://mrdarrengriffin.github.io/facet/editor/)**: a panel whose saved deck still held a page for a screen its firmware doesn't have (saved by an earlier version) stopped the editor at once with a script error. The editor now leaves that page out and lists it as Removed, so Save works again. <sub>#219</sub>

## After updating

Open the editor once and press Save if it lists a screen as Removed: that clears the old page from the panel.
