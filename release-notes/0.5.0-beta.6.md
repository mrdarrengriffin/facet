Home Assistant's update dialog now lists everything since your version. If your panel skipped a release or two, you see what changed in each of them, newest first, not just the latest.

## New

- **A Dev update channel for trying fixes early.** Set Update channel to Dev and the panel is offered a build of the latest code each night something changes. It is untested on a panel, so it can break things: switch back to Beta or Stable whenever you like. #102

## Improved

- **The update lists everything since your version.** When an update is offered, the dialog shows the notes of every version between the one on your panel and the new one, each under its own heading, so nothing you skipped goes unseen. #106

## Known issues

- **The update card can show Installing for about two minutes after the panel restarts.** That is the new firmware settling: don't unplug the panel until it reads up to date. If it stays on Installing longer, tell us on #55.
- **A Guition panel once restarted on tapping Allow for a new API key straight after Revoke all.** Not reproduced since; the key is still saved. #92
