A small fix release: Home Assistant now shows the right Facet version on the panel's device page, and every release comes with written notes, on GitHub and in Home Assistant's update card.

## Improved

- **Release notes you can read.** Every release lists what's new, what's fixed, anything to do after updating and known issues. Home Assistant's update card shows the short version, with a link to the full notes on GitHub. #105

## Fixed

- **The device page shows the real version.** On beta firmware, Home Assistant's device page (and the ESPHome Device Builder's import) said 0.4.0-dev while the update card said the real version. Both now say the same. #104

## Known issues

- **The update card can show Installing for about two minutes after the panel restarts.** That is the new firmware settling: don't unplug the panel until it reads up to date. If it stays on Installing longer, tell us on #55.
- **A Guition panel once restarted on tapping Allow for a new API key straight after Revoke all.** Not reproduced since; the key is still saved. #92
