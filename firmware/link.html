Link this panel to Home Assistant

The panel reads its own lists of your lights, sensors and calendars from Home Assistant with this address and token. It keeps them, and never shows the token back.

Create a token

Opens your Home Assistant profile. Create a long-lived token there, copy it, and paste it here.

A user of its own (best):

  1. In Home Assistant, Settings, People, Users: add a user for this panel, not an administrator.
  2. Log in as that user once (a private window), and create its long-lived token there.
  3. Paste that token above.
