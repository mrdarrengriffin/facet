The time, the date line and the clock faces now run on the panel renderer. Digits sit in fixed cells so the time never shifts as it changes, with the colon raised onto the figures. There are four faces: big digits, a dotted ring with a seconds dot going round, an analogue face with thin hands and an orange seconds hand, and a compact header clock. Each face is built from the same Time, Date line and tick ring used everywhere else.
