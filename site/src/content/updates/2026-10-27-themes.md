A theme file now restyles every screen built on the new renderer while it runs: cards, buttons, the dial's handle and
scale, the header and the page frame take the theme's colours, edges, bevels and shadows, with nothing rebuilt. Two
themes ship beside Facet, Blockcraft and Win98, and a theme that would make text hard to read or hide a button press is
refused before it reaches the screen.

Themes bring their own type too: Blockcraft draws in Monocraft and Win98 in W95FA (open-licence pixel fonts), without
moving a line. Pixel themes draw arcs, scale marks, the handle and icons in whole pixels of the theme's grid, with no
smoothing, so they look crisp rather than blurred.

Win98 now reads as real windows: the title bar runs to the window's edges with its buttons set just inside it, cards
are small windows with their own title bar, and a segmented control is a row of toolbar buttons with the chosen one
pressed in. A theme may move padding from a frame into its title bar this way, but never add or remove it, so nothing
on the screen gets less room.

Pick the theme on the panel under Settings > Theme (Mode keeps light and dark), or send your own from Home Assistant
with the `facet_theme` action: the panel checks the file itself, keeps it through restarts, and answers with exactly
what it refused and where, so a bad file never changes the screen.
