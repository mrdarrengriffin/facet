A freshly installed panel now opens on the Set up screen by itself: the code and password for its hotspot, then each
step as it happens (joining your Wi-Fi, could not join, "add me in Home Assistant", added). Once Home Assistant has
added it, Home opens with a short "Set up: done". If Home Assistant refuses the panel's actions, the panel says where to
turn them on. The editor now comes with the installed firmware on both boards, and firmware can no longer be uploaded
from a browser on the network: updates come from Home Assistant or the USB installer.
