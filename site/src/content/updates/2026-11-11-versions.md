Facet is in beta as a whole while it is 0.x, so its finished versions drop the beta numbers: the next one is 0.5.0,
and panels on 0.5.0-beta.10 see it as an update. From then on 0.6, 0.7 and on are feature releases, with fix
releases like 0.6.1 only when something can't wait. The Stable update channel is now called Release (a panel set to
Stable is on it already, with nothing to do); Beta is where the next version's test builds go, and Dev (nightly) stays.
