The first release of Facet: a wall panel UI for Home Assistant on two 4" touch panels, the Waveshare ESP32-P4-86
(720 x 720) and the Guition ESP32-S3-4848S040 (480 x 480). Both get the same layout; the 480 panel is the reference
size and the 720 panel draws it at 1.5x.

**Install** from the docs site's Install page in Chrome or Edge over a USB-C data cable: no ESPHome setup, no build
tools. On first boot the panel shows Set up: join your Wi-Fi from your phone (or over Bluetooth on the Waveshare), add
it in Home Assistant, and it lands on Home with its screens ready.

**The screens:** Home, Clock, Timer, Light and a room of lights, Media, Weather (and the next five days), Moon,
Calendar and Energy, with Settings, Set up and toasts. Dark, light and auto, with the accent colours. Screens change
as soon as you tap: the panel keeps them built. Each screen's settings (its entities, where its data comes from, its
options) are on the panel under Settings > Screens.

**The panel's own editor**: open the panel's address in a browser to arrange its Homes and their
cards, put the screens in order, set each screen up, and save it all to the panel in one step.

**Updates** arrive in Home Assistant and install from there; if an update goes wrong, the panel boots the previous one.
