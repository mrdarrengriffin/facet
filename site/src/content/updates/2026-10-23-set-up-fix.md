On a real panel the Set up screen lost everything but its code after the first step (a phone joining the hotspot,
then joining your Wi-Fi): the title, the words, the name and address were gone and the code sat in the top-left
corner. Each step now keeps its place. The screen checks also go through every step as an update, not only as a fresh
screen, so this kind of slip is caught before a release. Installer 0.4.0-public.3 has the fix.
