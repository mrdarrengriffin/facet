Plug a panel into a computer, pick it on the new Install page and press Install; Wi-Fi comes right after. A new Set up screen shows a fresh panel's way onto your Wi-Fi: a code to join its own hotspot, with a password made for that panel, and every step until Home Assistant has added it.
